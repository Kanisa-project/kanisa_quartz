   Kanisa is an art project that contains [[kanisaShell]].


## Texioty
[[Texioty]] is made up of two parts, [[texoty]] and [[texity]]. Texity allows you to input commands, while texoty shows you output from any [[TexHelpers|helper]] interaction. The first commands to learn and understand are the 'welcome' 'commands' 'help' ones.


## Regis and Repos
A [[BaseRegistry|registry]] is a repository that is being used in a Texioty environment. A repository will hold any helpers created or downloaded by a user. 

A repository is how you can share helpers, a registry allows you to use helpers.


> [!NOTE] Registries
> Registries contain fully featured helpers that are active and ready to be used in Texioty. The helpers may contain internal errors,  nothing that would break kanisaShell as a whole.

> [!NOTE] Repositories
> Repositories contain all helpers, whether fully developed or in development. These helpers are more sensitive and might cause external errors that could break kanisaShell.

   The registry for commands holds every command made available by the [[helper_registry]]. The registry also determines a commands active status by monitoring the current [[Texioty#Modes|mode]] of Texioty.

### Inactive Commands
   An inactive command is exactly as it sounds, it's a command that is available, just not usable in the current mode.


### Active Commands
Active commands are actively available commands. There are three commands that are always active

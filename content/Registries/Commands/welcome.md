The `welcome` command shows a "front page" look at the Texioty environment, which can include stock prices, bible verses, TCG card values, random facts of the day, inspiring quotes and a whole lot of other stuffs. With plenty of customization options, it can be very unique and personal to any user on the system.

`welcome` is designed to be used in any mode; show progress of the current prompt, the dates of current entries

### setup
An optional argument is "`modify`", this allows the user to modify what is shown for the `welcome` command.

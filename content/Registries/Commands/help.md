The `help` command is the more complicated beginner command. It accepts one of two different optional arguments, `(GROUP_TAG)` or `(COMMAND_NAME)`. 


## GROUP_TAG
Using the `(GROUP_TAG)` argument gives more details about the chosen group tag, certain ones come stock with Texioty:


| Helper       | Group Tag | Description                        |
| ------------ | --------- | ---------------------------------- |
| Texioty      | TXTY      | The system as a whole.             |
| Digiary      | DIRY      | The diary mode portion of Texioty. |
| PromptRunner | PRUN      | Runs questionnaire prompts.        |


## COMMAND_NAME
Using the `(COMMAND_NAME)` argument gives you full details of the named command. The first ones to learn are pretty simple:

| Command Name | Short Description                             |
| ------------ | --------------------------------------------- |
| [[welcome]]  | Shows a welcoming screen of the current mode. |
| [[Commands]] | Shows a list of all available commands.       |
| [[help]]     | Shows a helping message, based on argument    |

The number and names of commands full depend on the Texioty environment.

   TexHelpers are python packages that allow [[Texioty/Texioty]] to do more better things. They can be for playing gaims, sending messages, generating images or audio and more.

There are three primary focuses for a TexHelper:
 - Mode setter
 - Prompt runner
 - Widget display



## Mode Setter
Texioty is able to adopt several different modes, one at a time. [[Texioty#Default|Default]], [[Digiary]], Questionnaire, and Gaim are the first ones to be developed.



## Digiary
   Digiary is a helper that puts Texioty into [[Diary|diary mode]], so you can write line by line into a digital diary, "digiary". There is also the ability to read past entries.

## BasePrompt
[[BasePrompt]] is the basic model of a promptaire. It houses the functions and variables for smooth questioning and decision making.

## Gaims
A gaim is a game within the [[Kanisa Shell]] system.

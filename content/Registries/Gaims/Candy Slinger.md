
Candy slinger is a game of slinging candies around town. You can buy anything that is available from the area you're in or sell any of your pieces in your inventory. Moving between areas can spark a random event, but the main goal is to make maximum profit.

### Commands

| Command |                       Short Description                        |
| :-----: | :------------------------------------------------------------: |
|  move   |    Doesn't matter where you were, only where you're going.     |
|   buy   |   You gotta buy something in order to sell that some thing.    |
|  sell   | If you earned it, you own it, if you own it, you can trade it. |

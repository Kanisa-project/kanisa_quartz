## Prep machines
   Prep machine profiles accept an image chosen by a user and manipulates it based on the values of the profile being used.
### extruders
   Pulls out rows of pixels from an image, with each profile adjusting the pulled piece differently.
### mixers
   Takes spots of pixels from an image, with each profile "powderizing" the spot differently.
### slicers
   Cuts pixels of an image, with each profile

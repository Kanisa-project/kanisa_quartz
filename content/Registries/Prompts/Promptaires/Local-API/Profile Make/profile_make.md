profile_make is a [[Prompts|promptaire]] set up for making profiles of many kinds. Profiles come in many different capacities, and are used for a wide variety of tasks. A **user** profile allows a person to use certain features, while a tcg profile allows for trading card game shenanigans.

#### User
A profile for a user, pretty simple. If you need a profile that has to "login", or keep track of a score, or display a persons achievements, you probably need a user profile.

#### Gaim
A gaim profile is for letting a gaim engine know what is allowed or not. It contains the necessary things for movement and environment stuff.

#### Worx
If you want to manipulate an image, there are a lot of equipment to use. Each worx equipment specializes in a certain part of altering the image.

#### TCG
These profiles contain the searching terms and what types of LABs are available for the profile itself.

#### LAB (Logic Art Builder)
A [[tcg_lab#Labs|lab_profile]] is how one would work with a batch of TCG cards. In the lab, you can make a randomized deck list, or depict some new images and plenty more.

##### Depictinator
   A [[depictinator]] profile defines some coloring aspects, overall shape/size, and some features of the generated image.
   
##### Puzzler
   A [[puzzlers]] profile contains what type of puzzle, along with the content for the puzzle.
   
##### Deckster
   A [[decksters]] profile has the portions of the deck being generated and how to find which cards to add.

##### TC-blender
   A [[tc-blender]] profile can contain a TCG to pull a random card from, or you can select specific cards to blend into a non-existent card.

##### Downloader
   A [[downloader]] profile contain the search criteria for which cards to download.

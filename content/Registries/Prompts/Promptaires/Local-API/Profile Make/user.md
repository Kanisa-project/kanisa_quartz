 Each user profile starts out as a basic Texioty set of saving attributes (outlined below), but can expand into many different savable necessities. Texioty can have multiple user profiles in it's registry, but only one profile can be active at a time.

### Texioty
   Texioty is the most basic of user profiles, it mainly has access to save:
   - color themes
   - command scripts
   - digiary entries

### Laser Tag
   Laser tag attributes include:
   - weapon upgrades
   - shield modifications
   - player stats (score, K/D ratio, accuracy %)

### Gaims
   Gaims is more of a registry, so each gaim would need its own set of savers, but generally:
   - high score and score history
   - active gaims

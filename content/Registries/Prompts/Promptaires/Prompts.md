Prompts are [[TexHelpers]] that ask questions, get answers and then performs tasks at the end. A questionnaire prompt will put Texioty in Questionnaire mode.

## Questions
There are three main types of questions:
 - Decision
 - Strict
 - Loose

### Decision
A decision question is a multiple choice question, it's a question that requires specific responses.

### Strict
A strict question needs a type of answer for a response. The main types of responses fall into python datatype categories:

| Datatype | Description                          |
| -------- | ------------------------------------ |
| String   | Letters, numbers and symbols.        |
| Integer  | A whole number, negative or positive |
| Float    | A number with a decimal.             |
| Boolean  | True or False                        |

### Loose
 A loose question has the most leeway, and can accept any type of answer for a response.

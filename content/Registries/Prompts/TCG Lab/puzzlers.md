From hangman to word search, there are a lot of word type puzzles.


## Word games
   Games that focus on words and can puzzle people for a while.

| Puzzle      | Description                                                   |
| ----------- | ------------------------------------------------------------- |
| Hangman     | A hidden phrase meant to be guessed one letter at a time.     |
| Word Search | Grid of letters with words hidden within.                     |
| Crossword   | A list of clues for filling in blank squares with characters. |
| Riddle      | Vague clues towards a hint for a phrase to guess.             |
| Anagrams    | Shuffled up letters to make a phrase from another phrase.     |
| Madlibs     | Fill in blank words of specific types to get a fun story.     |

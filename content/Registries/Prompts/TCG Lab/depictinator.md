To show or represent by a drawing, painting or other art form, is a depiction. This will take a card, any card, and generate a piece of abstract art.

### Depiction Stylers
   These will style a depiction for the purpose of creation. Its the main way for the image to be used.

| Depiction Style |                        Explanation                         |
| :-------------: | :--------------------------------------------------------: |
|     Playmat     |    Generates a rectangular image, meant for a playmat.     |
|     Sticker     |            Print a sticker with these designs.             |
|     Sleeves     | Used for printing on the back of sleeves to protect cards. |
|    Wallpaper    |                 Wallpapers for computers.                  |
|  Discord Emoji  |     An emoji for discord is small, about 24x24 pixels      |
|     Avatar      |           A social media avatar of abstraction.            |
|     Banner      |           Social media banner on a persons page.           |
|      Tile       |         Rectangular avatar for tiling, if desired.         |
